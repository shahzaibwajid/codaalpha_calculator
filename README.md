# 🧮 Calculator

A simple and responsive web-based calculator developed using **HTML, CSS, and JavaScript**. This project was created as part of my **CodeAlpha Frontend Development Internship** to practice frontend development and JavaScript functionality.

## 📌 Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🔢 Decimal number calculations
* 🧹 Clear (`C`) button
* ⌫ Delete (`DEL`) button
* ⌨️ Full keyboard support
* ↵ `Enter` key for calculation
* ⌫ `Backspace` key to delete the last character
* `Escape` key to clear the display
* ⚠️ Basic error handling
* 📱 Responsive and clean user interface

## 🛠️ Technologies Used

* **HTML5** — Structure of the calculator
* **CSS3** — Styling, layout, buttons, and visual design
* **JavaScript** — Calculator functionality and keyboard support
* **GitHub** — Source code management
* **GitHub Pages** — Website deployment

| ----------- | --------------------- |
| `0–9`       | Enter numbers         |

| `-`         | Subtraction           |
| `*`         | Multiplication        |
| `/`         | Division              |
| `.`         | Decimal               |
| `Enter`     | Calculate             |
| `Backspace` | Delete last character |
| `Escape`    | Clear display         |

## 🚀 How to Use

1. Open the calculator website.
2. Enter numbers using the calculator buttons or your keyboard.
3. Select an arithmetic operator.
4. Enter the second number.
5. Press `=` or `Enter`.
6. The result will be displayed on the screen.

### Example

```text
7 + 5 = 12
```

You can also perform the same calculation using the keyboard:

```text
7 → + → 5 → Enter
```
